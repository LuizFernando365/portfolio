# Meu Portfólio Profissional

Este é o repositório do meu site de portfólio pessoal, desenvolvido para exibir meus serviços, habilidades e formas de contato para potenciais clientes e empregadores.
Esse site é totalmente fictício, criado para fins de aprendizado, os serviços oferecidos não são reais.

## Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias:
* **HTML5** (Estruturação da página)
* **CSS3** (Estilização, layout e responsividade)
* **JavaScript** (Interatividade e animações)

## Funcionalidades

* **Design Responsivo:** Adaptado para diferentes tamanhos de tela (computadores e celulares).
* **Seção de Serviços:** Apresentação clara dos serviços oferecidos.
* **Animações Suaves:** Melhoria na experiência do usuário utilizando JavaScript e CSS.
* **Links de Contato Diretos:** Facilidade para comunicação rápida.
